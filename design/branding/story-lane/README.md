# Story Lane branding

## Selected identity: 07 — Shot / Reverse Shot

The selected mark uses opposing dialogue panels inside viewfinder corners, connecting screenplay writing with film and television. The user selected option 07 after reviewing both concept rounds.

- [Selected one-color icon](selected-07/07-shot-reverse-shot-mono.svg)

### Typography and palette

The app retains option 07's symbol and uses a consistent sans-serif interface following the typography refinement:

- Interface font stack: `"Segoe UI Variable", "Segoe UI", -apple-system, BlinkMacSystemFont, Arial, sans-serif` (system fonts; no downloaded font required). The original SVG explorations retain their original Arial wordmarks.
- Weight: `650`.
- Tracking: `-0.04375em`, equivalent to the SVG's `-2.8` at `64px`.
- Header title size: `22px` desktop, `18px` on small screens; subtitle `11px` / `10px` in sentence case.
- Ink background: `#172622`.
- Warm white: `#f2f0e5`.
- Mint: `#8ddaaf`.
- App accent: `#8ddaaf` in dark mode, `#247454` in light mode for readable controls and links.

## Active app assets

The app serves the selected design from `app/public/brand/story-lane-mark.svg` and `app/public/brand/story-lane-logo.svg`. A one-color mark is available at `app/public/brand/story-lane-mark-mono.svg`. The favicon uses the original square mark with `?v=07`. The header renders option 07's exact paths inline without a background, so the symbol follows the app's selected theme. A transparent standalone export is available at `app/public/brand/story-lane-header-mark.svg`.

These files are a reference snapshot. Future brand changes should retain the exploratory originals and update the active app assets deliberately.
