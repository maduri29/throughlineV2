Two Devices, One Story

Throughline is getting automatic cloud sync so one writer can work from several machines at different times. This drives that state machine by hand.

The question: when two devices edit the same story and both try to save, the plan is to reject the stale save and keep the loser's version as a separate story rather than overwrite. Does that actually hold up — and can any sequence of edits, pushes and disconnections make written work disappear? Every edit is a numbered token, so you can see for yourself.
